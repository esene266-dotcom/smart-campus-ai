# NEXUS AI CAMPUS

Учебный веб-прототип панели управления умным кампусом.

## Функции
- Dashboard с KPI и графиком энергопотребления (Chart.js)
- 12 демонстрационных аудиторий с температурой, CO₂, занятостью и энергопотреблением
- 24 демонстрационных IoT-устройства
- AI Analytics на основе прозрачных пороговых правил
- Создание, изменение статуса и удаление инцидентов
- Поиск, фильтрация, светлая/тёмная тема
- Сохранение заявок и темы в localStorage
- Адаптивная вёрстка для телефона и компьютера

## Запуск
Открой `index.html` в браузере. Для удобной разработки можно использовать VS Code и Live Server.

## Публикация через GitHub Pages
1. Создай публичный репозиторий `nexus-ai-campus`.
2. Загрузи `index.html`, `style.css`, `script.js`, `README.md` в корень репозитория.
3. Открой Settings → Pages.
4. В Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/(root)`, нажми Save.

## Важно
Это демонстрационный учебный прототип. Данные датчиков имитируются и не поступают с реальных устройств. AI Analytics использует пороговые правила, а не обученную нейросеть. Chart.js загружается через CDN, поэтому график требует подключения к интернету.
